# CSV my PDF

Upload any bank statement PDF — digital or scanned — and receive a clean, structured CSV containing every transaction.

**Columns:** `date`, `payment_type`, `details`, `paid_out`, `paid_in`, `balance`

**Requires:** `GROQ_API_KEY` set as a Hugging Face Secret.
